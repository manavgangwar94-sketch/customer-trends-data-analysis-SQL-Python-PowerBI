# Customer Shopping Behavior Analysis

An end-to-end data analytics project analyzing customer shopping trends from retail data using **SQL**, **Python**, and **Power BI**.

---

## Project Overview

This project simulates a corporate-grade analytics workflow — from raw data to actionable business insights.

| Stage | Tool | Description |
|---|---|---|
| Data Preparation & EDA | Python | Clean, transform, and explore the dataset |
| Data Analysis | SQL | Query customer segments, loyalty, and purchase drivers |
| Visualization | Power BI | Interactive dashboard for stakeholder decision-making |
| Reporting | PDF / PPTX | Summary of findings and business recommendations |

---

## Project Structure

```
├── Customer_Shopping_Behavior_Analysis.ipynb   # Python EDA notebook
├── customer_behavior_sql_queries.sql           # SQL business queries
├── customer_behavior_dashboard.pbix            # Power BI dashboard
├── customer_shopping_behavior.csv              # Raw dataset
├── Business Problem Document.pdf              # Problem statement
├── Customer Shopping Behavior Analysis.pdf    # Final report
└── Customer-Shopping-Behavior-Analysis.pptx  # Presentation deck
```

## How to Run

1. **Clone the repo**
   ```bash
   git clone https://github.com/YOUR-USERNAME/customer-trends-data-analysis-SQL-Python-PowerBI.git
   cd customer-trends-data-analysis-SQL-Python-PowerBI
   ```

2. **Run the Python notebook**
   Open `Customer_Shopping_Behavior_Analysis.ipynb` and run all cells to clean the data and load it into your SQL database.

3. **Run SQL queries**
   Open `customer_behavior_sql_queries.sql` in MySQL / PostgreSQL / MS SQL Server and execute the queries.

4. **Open the Power BI dashboard**
   Open `customer_behavior_dashboard.pbix`, connect it to your SQL database, and explore the visuals.

## Key Insights

- Analyzed customer segments by age, gender, and purchase frequency
- Identified top product categories and seasonal buying trends
- Measured impact of discounts and promo codes on revenue
- Built loyalty metrics to classify high-value vs low-value customers
